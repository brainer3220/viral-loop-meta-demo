## Recording variants

- Rehearsal: permanently visible "Offline rehearsal" label, template directions,
  synthetic coffee illustration, zero Meta calls. This is not an eligible-entry
  claim and must not be presented as a finished live Meta demo.
- Live integration: only after account credits, prices, asset rights and exact
  request approval are verified. Keep the recorded response IDs and media hashes.
  If a call fails or is uncertain, stop and inspect it. Do not replay automatically.

## Before the final capture

1. Verify the public source commit and the organizer's current submission fields.
2. Resolve the license choice with the owner. Public visibility is not proof that
   the organizer's open-source requirement is met.
3. Run the offline tests, then separately verify each authorized live request.
4. Use one fictional brief consistently. Never show real keys, private input,
   account billing pages or production configuration in the recording.
5. Record at a readable size, check all frames at desktop and phone widths, and
   inspect full audio and video. Check actual duration with FFprobe.
6. Final submission remains a separate action. Do not submit this plan or a
   rehearsal as if a successful live integration has been demonstrated.
